# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-07-08

### Added
- DirectComposition and native Win32 layered DWM integration.
- Hardware-accelerated transparent floating window substrate (`FastOverlayWindow`).
- Dynamic input transparency toggle (`setClickThrough`).
- Instant hardware visual node translation (`setVisualOffset`).
- Embedded Swing container integration (`FastOverlayPanel`).
- Automated native library resolution and extraction via `FastCore`.
- Standalone 60 FPS animated demo in `examples/Demo`.
